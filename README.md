## Learning Path

A practical progression through this collection is:

1. Start with **Nmap Service Trail** to practice service and network discovery.
2. Continue with **Silent Ports: Hidden Services** to investigate less obvious service exposure.
3. Explore the **Redis** labs to become familiar with Redis-oriented security analysis.
4. Study **Momentum Cipher** and **Cipher to Root** for cryptography-focused challenges.
5. Progress to the **PrivEsc** and **Root** labs to practice Linux privilege-boundary analysis.
6. Finish with the sandbox-focused challenges to connect isolation, service discovery, and privilege concepts.

## How to Use the Labs

1. Select a challenge from the collection.
2. Read the lab instructions carefully.
3. Identify the primary security concept suggested by the challenge.
4. Work exclusively inside the authorized lab environment.
5. Record your observations, commands, errors, and findings.
6. Determine the underlying security weakness or configuration issue.
7. Document defensive mitigations and secure configuration ideas where applicable.

Do not test techniques against systems you do not own or have explicit authorization to assess.
